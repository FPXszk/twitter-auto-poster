# バズ特化リデザイン実装計画

## 概要

投資系コンテンツからバズツイート転載・自動エンゲージメント特化構成へ全体を再設計する。

## 背景・方針転換

- **停止**: 投資系ワークフロー（朝夕サマリー・銘柄更新）
- **継続**: バズツイート自動投稿・自動フォロー/フォローバック・自動いいね
- **リネーム**: `post_invest` → `post_buz`（バズツイート転載）
- **ソース変更**: 特定3アカウントのバズツイートをラウンドロビンで収集
- **投稿形式変更**: 引用ツイート・スレッドを停止し常に単発280字以内でポスト
- **フォロー先変更**: `paurooteri` → `tkzwgrs` のフォロワーから

## ターゲットアカウント

- `gorillataxjp`
- `zanEngineer`
- `tkzwgrs`

## バズ検索クエリ設計

| ソースID | クエリ | 規模 |
|---------|-------|------|
| buz-gorillataxjp-big | `from:gorillataxjp -is:retweet -is:reply min_retweets:52 min_faves:3000` | 大バズ |
| buz-gorillataxjp-small | `from:gorillataxjp -is:retweet -is:reply min_retweets:52 min_faves:700` | 小バズ |
| buz-zanengineer-big | `from:zanEngineer -is:retweet -is:reply min_retweets:52 min_faves:3000` | 大バズ |
| buz-zanengineer-small | `from:zanEngineer -is:retweet -is:reply min_retweets:52 min_faves:700` | 小バズ |
| buz-tkzwgrs-big | `from:tkzwgrs -is:retweet -is:reply min_retweets:52 min_faves:3000` | 大バズ |
| buz-tkzwgrs-small | `from:tkzwgrs -is:retweet -is:reply min_retweets:52 min_faves:700` | 小バズ |

選択モード: `round_robin`（6ソースをローテーション）

## 投稿仕様

- 引用ツイート: **なし**（`source_reference_mode: "url"` 維持、URLも末尾に付けない）
- スレッド: **なし**（`single_post_max_length: 280` 維持）
- 文字数: **常に280字以内**（Copilotが圧縮）
- プレフィックス: **なし**（`Market watch:` 削除）
- 要約プロバイダー: `copilot_cli` 維持、プロンプト更新
