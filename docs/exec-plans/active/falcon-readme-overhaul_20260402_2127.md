## 1. プロジェクト理解サマリー

`Falcon_script/` は **Falcon自動検査装置（PCS52マシン）** 用の検査スクリプト・ドライバ・設定・ツール群を管理するディレクトリである。

主要な構成要素は以下の通り：

| 領域 | 主要ディレクトリ | 役割 |
|------|------------------|------|
| 検査スクリプト開発ワークスペース | `PgDebug/Falcon/` | src→dst のスクリプト生成・パッチ適用。modify_script.py がメインツール |
| 検査スクリプト本体 | `Programs/` | Falcon に実際にロードされるスクリプト群 |
| テスター設定 | `Tester.cfg`, `Tester/` | ProgramType=Falcon, MachineType=PCS52 の装置設定 |
| ドライバ・ランタイム | `Driver/` | testerPgStart.exe, AtelierCtrlWrapper2.dll 等 |
| 計測・波形・リレー定義 | `Meas/`, `Wave/`, `RELAY/` | ADC/DAC計測ポイント・リレーパターン定義 |
| デバイス・メディア管理 | `Device/`, `Media/`, `IMG/` | DUT定義・メディアイメージ |
| ETH通信ログ | `EthLog/` | Ethernet通信デバッグログ |
| VxWorks関連 | `VxWorks/` | リアルタイムOS関連アセット |
| デバッグ結果 | `debug_result/` | 検査デバッグの結果格納 |
| 作業領域 | `Work/`, `Data/` | 一時的なデータ・作業ファイル |

現行 README.md の問題点：
- `00_need_deploy`, `Info/PCS52`, `Script/PCS52` がリポジトリルートにあるかのように記述されているが、実際にはこれらは `PgDebug/Falcon/` 配下の src/dst サブツリーに存在する
- ディレクトリ全体像（Driver, Tester, Programs, Meas, RELAY 等）が一切記載されていない
- modify_script.py の説明は詳細で有用だが、プロジェクト概要としての構成が欠けている
- 「機能追加テンプレート」セクション（約220行）がREADMEの半分以上を占め、リファレンスとしては有用だがプロジェクト概要READMEには不適切
